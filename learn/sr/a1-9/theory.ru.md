## Красная юбка

Наташе нужна новая юбка для вечера народных танцев. Луис идёт с ней по магазинам.

> — **Добар дан**{Добрый день}! **Тражим сукњу**{Я ищу юбку}.
> — **Које боје**{Какого цвета}?
> — **Црвену**{Красную}, **са везом**{с вышивкой}.
> — **Ова је веома лепа**{Вот эта очень красивая}. **Изволите**{Пожалуйста}!
> — **Могу ли да је пробам**{Можно её примерить}?
> — Наравно. **Кабина је тамо**{Примерочная вон там}.

Наташа выходит из примерочной. Луис улыбается:

> — **Ова сукња ти одлично стоји**{Эта юбка тебе отлично идёт}!
> — **Колико кошта**{Сколько стоит}?
> — **Три хиљаде динара**{Три тысячи динаров}.
> — **Узећу је**{Беру}!

## 1. Цвета и согласование прилагательных

Прилагательные согласуются с существительным, как в русском: мужской род (без окончания), женский **-а**, средний **-о**.

| | мужской | женский | средний | Русский |
|---|---|---|---|---|
| | црвен шал | црвен**а** сукња | црвен**о** вино | красный |
| | плав капут | плав**а** кошуља | плав**о** небо | синий, голубой |
| | зелен | зелен**а** | зелен**о** | зелёный |
| | жут | жут**а** | жут**о** | жёлтый |
| | бео | бел**а** | бел**о** | белый |
| | црн | црн**а** | црн**о** | чёрный |
| | сив | сив**а** | сив**о** | серый |
| | браон, розе | браон, розе | браон, розе | коричневый, розовый (не меняются) |

В винительном падеже женский род тоже получает **-у**: *Тражим црвен**у** сукњ**у**.* — Ищу красную юбку.

## 2. Этот и тот — ОВАЈ, ТАЈ

| | мужской | женский | средний |
|---|---|---|---|
| этот | **овај** шал | **ова** сукња | **ово** вино |
| тот | **тај** капут | **та** хаљина | **то** небо |

## 3. Сколько стоит? — КОЛИКО КОШТА?

- **Колико кошта** ова сукња? — Сколько стоит эта юбка?
- **Колико коштају** ципеле? — Сколько стоят туфли?

| | | | |
|---|---|---|---|
| 100 | сто | 600 | шесто |
| 200 | двеста | 700 | седамсто |
| 300 | триста | 800 | осамсто |
| 400 | четиристо | 900 | деветсто |
| 500 | петсто | 1000 | хиљаду |

**Хиљаду** динара; **две, три, четири хиљаде**; **пет хиљада** — как «тысяча, тысячи, тысяч».

## 4. ДА + настоящее время

Там, где в русском инфинитив, сербы часто говорят **да + настоящее время**:

- **Могу ли да пробам?** — Можно примерить? (букв. «могу ли, чтобы я примерила»)
- **Желим да купим** сукњу. — Хочу купить юбку.
- **Морам да платим.** — Мне нужно заплатить.
