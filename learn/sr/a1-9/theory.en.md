## The red skirt

Natasha wants a new skirt for a folk dance evening. Luis goes shopping with her.

> — **Добар дан**{Good afternoon}! **Тражим сукњу**{I’m looking for a skirt}.
> — **Које боје**{What colour}?
> — **Црвену**{Red}, **са везом**{with embroidery}.
> — **Ова је веома лепа**{This one is very pretty}. **Изволите**{Here you are}!
> — **Могу ли да је пробам**{May I try it on}?
> — Наравно. **Кабина је тамо**{The fitting room is over there}.

Natasha comes out of the fitting room. Luis smiles:

> — **Ова сукња ти одлично стоји**{This skirt really suits you}!
> — **Колико кошта**{How much is it}?
> — **Три хиљаде динара**{Three thousand dinars}.
> — **Узећу је**{I’ll take it}!

## 1. Colours — and adjective agreement

Adjectives agree with the noun: masculine (no ending), feminine **-а**, neuter **-о**.

| | masculine | feminine | neuter | English |
|---|---|---|---|---|
| | црвен шал | црвен**а** сукња | црвен**о** вино | red |
| | плав капут | плав**а** кошуља | плав**о** небо | blue |
| | зелен | зелен**а** | зелен**о** | green |
| | жут | жут**а** | жут**о** | yellow |
| | бео | бел**а** | бел**о** | white |
| | црн | црн**а** | црн**о** | black |
| | сив | сив**а** | сив**о** | grey |
| | браон, розе | браон, розе | браон, розе | brown, pink (don’t change) |

In the accusative, feminine adjectives also take **-у**: *Тражим црвен**у** сукњ**у**.*

## 2. This and that — ОВАЈ, ТАЈ

| | masculine | feminine | neuter |
|---|---|---|---|
| this | **овај** шал | **ова** сукња | **ово** вино |
| that | **тај** капут | **та** хаљина | **то** небо |

## 3. How much is it? — КОЛИКО КОШТА?

- **Колико кошта** ова сукња? — How much is this skirt?
- **Колико коштају** ципеле? — How much are the shoes?

| | | | |
|---|---|---|---|
| 100 | сто | 600 | шесто |
| 200 | двеста | 700 | седамсто |
| 300 | триста | 800 | осамсто |
| 400 | четиристо | 900 | деветсто |
| 500 | петсто | 1000 | хиљаду |

**Хиљаду** динара; **две, три, четири хиљаде**; **пет хиљада**.

## 4. ДА + present — «to do something»

Serbian usually says **да + present tense** where English uses «to + verb»:

- **Могу ли да пробам?** — May I try it on?
- **Желим да купим** сукњу. — I want to buy a skirt.
- **Морам да платим.** — I have to pay.
