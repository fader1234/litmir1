## Где сливаются реки

Из первой главы «Дивљег часа»:

> Кроз Београд **теку две реке**{текут две реки}: **Сава и Дунав**{Сава и Дунай}. **Тамо где се реке спајају**{Там, где реки сливаются} **налази се**{находится} Калемегдан. Калемегдан је **велики парк и стара тврђава**{большой парк и старая крепость}.

Наташа показывает Луису город:

> — **Где смо сада**{Где мы сейчас}?
> — **У Кнез Михаиловој улици**{На улице Князя Михаила}. То је **главна улица**{главная улица} у Београду.
> — А **где је Калемегдан**{где Калемегдан}?
> — **На крају улице**{В конце улицы}. **Није далеко**{Недалеко}: пет минута **пешке**{пешком}.
> — **Има ли овде кафић**{Здесь есть кафе}?
> — Наравно! **Поред књижаре**{Рядом с книжным магазином}, **преко пута музеја**{напротив музея}.

## 1. Где? — ГДЕ ЈЕ…?

- **Где је** Калемегдан? — Где Калемегдан?
- **Где су** Наташа и Луис? — Где Наташа и Луис?
- **Где се налази** тврђава? — Где находится крепость?
- **Овде / тамо.** — Здесь / там. **Близу / далеко.** — Близко / далеко.

## 2. У или НА + местный падеж

Как в русском, «где?» требует падежа, который в сербском называется **локатив**:

| | Именительный | Где? | |
|---|---|---|---|
| **у** (в) | Београд | **у** Београд**у** | в Белграде |
| | парк | **у** парк**у** | в парке |
| | улица | **у** улиц**и** | на улице |
| | кафић | **у** кафић**у** | в кафе |
| **на** (на) | Калемегдан | **на** Калемегдан**у** | на Калемегдане |
| | трг | **на** трг**у** | на площади |
| | река | **на** рец**и** | на реке |
| | мост | **на** мост**у** | на мосту |

Окончания простые: мужской и средний род → **-у**, женский → **-и**. Внимание: «на улице» по-сербски — ***у** улици*!

## 3. Предлоги места

| Српски | Русский | Пример |
|---|---|---|
| поред | рядом с | поред књижаре |
| испред | перед | испред музеја |
| иза | за | иза цркве |
| изнад | над | изнад реке |
| испод | под | испод моста |
| између | между | између Саве и Дунава |
| преко пута | напротив | преко пута музеја |
| близу / далеко од | близко к / далеко от | близу центра |
| лево / десно | слева / справа | Музеј је лево. |

После этих предлогов слово стоит в **родительном падеже**, как часто и в русском: *поред **моста**, испред **музеја***.

## Проверьте себя

Луис је [[*у Београду|у Београд|на Београду]].

Тврђава је [[у Калемегдану|*на Калемегдану|на Калемегдан]].

Наташа је [[*у кафићу|у кафић|на кафићу]].

Кафић је поред [[књижара|*књижаре|књижари]].

[[*Где|Ко|Шта]] је Калемегдан?

Калемегдан је између Саве и [[Дунав|*Дунава|Дунаву]].

«На улице» по-сербски — «у улици». ( V / F ){V}

Калемегдан — это река. ( V / F ){F}
