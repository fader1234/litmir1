## Знакомьтесь: Наташа и Луис

Роман «Дивљи час»: аргентинец Луис гуляет по улице Кнез Михаилова в Белграде — и в него врезается электросамокат. На самокате — Наташа.

Наведите курсор на слово (или нажмите на него), чтобы увидеть перевод.

> — **Опростите**{Простите}! **Опростите**{Простите}! **Јесте ли добро?**{Вы в порядке?}
> — **Добро сам**{Я в порядке}, **хвала**{спасибо}. **Ја сам**{Я} Луис.
> — **Здраво**{Привет}, Луисе! **Зовем се**{Меня зовут} Наташа. **Драго ми је**{Очень приятно}.
> — **И мени**{Мне тоже}. **Ја сам из Аргентине**{Я из Аргентины}. **Ја сам туриста**{Я турист}.
> — **Ја сам из Београда**{Я из Белграда}. **Ја сам Српкиња**{Я сербка}. **Како си?**{Как дела?}
> — **Сада добро**{Теперь хорошо}! **Видимо се**{Увидимся}, Наташа!

## 1. Приветствия и прощания

| Српски | Русский |
|---|---|
| Здраво | Привет / Пока |
| Добар дан | Добрый день, здравствуйте |
| Добро јутро | Доброе утро |
| Добро вече | Добрый вечер |
| Лаку ноћ | Спокойной ночи |
| Довиђења | До свидания |
| Ћао / Видимо се | Пока / Увидимся |
| Хвала / Молим | Спасибо / Пожалуйста |

## 2. Как представиться

- **Како се зовеш? / Како се зовете?** — Как тебя зовут? / Как Вас зовут?
- **Зовем се Наташа. / Ја сам Наташа.** — Меня зовут Наташа. / Я Наташа.
- **Драго ми је.** — Очень приятно.
- **Како си? — Добро.** — Как дела? — Хорошо.

Как в чешском, в обращении имя меняется: *Луис → **Луисе***, *Милан → **Милане***.

## 3. Личные местоимения

| Српски | Русский |
|---|---|
| ја | я |
| ти | ты |
| он / она / оно | он / она / оно |
| ми | мы |
| ви / Ви | вы / Вы |
| они / оне / она | они |

Местоимение часто опускают: **Из Београда сам** = «Я из Белграда».

## 4. Глагол «бити»

В отличие от русского, сербское «быть» в настоящем времени **обязательно**: *Ја **сам** Наташа*.

| Лицо | БИТИ | Пример |
|---|---|---|
| ја | **сам** | Ја сам Наташа. |
| ти | **си** | Ти си туриста? |
| он / она | **је** | Луис је из Аргентине. |
| ми | **смо** | Ми смо пријатељи. |
| ви | **сте** | Ви сте из Русије? |
| они | **су** | Они су у Београду. |

Эти короткие формы не стоят в начале фразы: говорят *Ја сам Луис* или *Луис сам*, но не *Сам Луис*. Отрицание: **нисам, ниси, није, нисмо, нисте, нису**.

## 5. Откуда вы?

- **Одакле си? / Одакле сте?** — Откуда ты? / Откуда Вы?
- **Ја сам из Београда / из Москве.** — Я из Белграда / из Москвы.
- **Ја сам из Србије / из Аргентине.** — Я из Сербии / из Аргентины.

После **из** слово меняет окончание: *Београд → из Београда, Русија → из Русије*. Национальности:

| Он | Она | Русский |
|---|---|---|
| Србин | Српкиња | серб, сербка |
| Рус | Рускиња | русский, русская |
| Аргентинац | Аргентинка | аргентинец, аргентинка |
| Италијан | Италијанка | итальянец, итальянка |
| Шпанац | Шпањолка | испанец, испанка |
| Енглез | Енглескиња | англичанин, англичанка |

## 6. Произношение

| Буквы | Как читаются | Пример |
|---|---|---|
| ј (j) | «й» | ја, Србија |
| љ (lj), њ (nj) | «ль», «нь» | љубав, Шпањолка |
| ћ (ć), ч (č) | мягкое и твёрдое «ч» | ћао, чај |
| ђ (đ), џ (dž) | мягкое и твёрдое «дж» | Ђорђе, џем |
| х (h) | «х» | хвала |
| е | «э», не «е» | вече, Београд |

## 7. Полезно знать

В сербском **две азбуки** — кириллица и латиница, обе официальные: *Наташа = Nataša, хвала = hvala*. Правило Вука Караджича: «пиши как говоришь, читай как написано» — каждая буква всегда звучит одинаково. В упражнениях можно писать и латиницей — ответ сам превратится в кириллицу.

## Проверьте себя

Луис [[*је|сам|су]] из Аргентине.

Ја [[је|*сам|си]] Наташа.

Ми [[*смо|сте|су]] пријатељи.

Наташа је [[Србин|*Српкиња|Срби]].

Увече кажемо: [[Добро јутро|*Добро вече|Лаку ноћ]].

В сербском две официальные азбуки. ( V / F ){V}

В сербском, как в русском, «быть» в настоящем времени опускают. ( V / F ){F}
