## 2. Introducing yourself

- **Како се зовеш? / Како се зовете?** — What’s your name? (informal / formal)
- **Зовем се Наташа. / Ја сам Наташа.** — My name is Natasha. / I’m Natasha.
- **Драго ми је.** — Nice to meet you.
- **Како си? — Добро.** — How are you? — Fine.

As in Czech, a name changes when you address someone: *Луис → **Луисе***, *Милан → **Милане***.

## 3. Subject pronouns

| Српски | English |
|---|---|
| ја | I |
| ти | you (informal) |
| он / она / оно | he / she / it |
| ми | we |
| ви / Ви | you (plural / formal) |
| они / оне / она | they |

The pronoun is often dropped: **Из Београда сам** = "I’m from Belgrade".

## 4. The verb “бити”

As in English, Serbian needs the verb "to be": *Ја **сам** Наташа* — "I am Natasha".

| Person | БИТИ | Example |
|---|---|---|
| ја | **сам** | Ја сам Наташа. |
| ти | **си** | Ти си туриста? |
| он / она | **је** | Луис је из Аргентине. |
| ми | **смо** | Ми смо пријатељи. |
| ви | **сте** | Ви сте из Русије? |
| они | **су** | Они су у Београду. |

These short forms can’t start a sentence: you say *Ја сам Луис* or *Луис сам*, but not *Сам Луис*. The negative: **нисам, ниси, није, нисмо, нисте, нису**.

## 5. Where are you from?

- **Одакле си? / Одакле сте?** — Where are you from?
- **Ја сам из Београда / из Москве.** — I’m from Belgrade / from Moscow.
- **Ја сам из Србије / из Аргентине.** — I’m from Serbia / from Argentina.

After **из** ("from") the noun changes: *Београд → из Београда, Русија → из Русије*. Nationalities:

| He | She | English |
|---|---|---|
| Србин | Српкиња | Serbian |
| Рус | Рускиња | Russian |
| Аргентинац | Аргентинка | Argentinian |
| Италијан | Италијанка | Italian |
| Шпанац | Шпањолка | Spanish |
| Енглез | Енглескиња | English |

## 7. Good to know

Serbian has **two alphabets** — Cyrillic and Latin, both official: *Наташа = Nataša, хвала = hvala*. Vuk Karadžić’s rule: "write as you speak, read as it is written" — each letter always has the same sound. In the exercises you can type in Latin letters: the answer is converted to Cyrillic automatically.
