## Знакомьтесь: Наташа и Луис

Роман «La Sovaĝa Horo: La Savo de Zmaj»: дракона Змая взяли в плен в Праге, и Луис с Наташей едут его спасать. В пражском книжном магазине их встречает продавщица с картой семи звёзд.

Наведите курсор на слово (или нажмите на него), чтобы увидеть перевод.

> — **Saluton**{Привет, здравствуйте}! **Mi estas**{Я} Nataŝa, **kaj li estas**{а он} Luis.
> — **Bonvenon**{Добро пожаловать}! **Mi nomiĝas**{Меня зовут} Eliška. **Kiel vi fartas?**{Как дела?}
> — **Bone, dankon**{Хорошо, спасибо}. **Ni estas el**{Мы из} Beogrado.
> — **Ĉu vi estas serbo?**{Вы серб?}, **ŝi demandas**{спрашивает она} Luis-on.
> — **Ne**{Нет}, **mi estas argentinano**{я аргентинец}. **Nataŝa estas serbino**{Наташа — сербка}.
> — **Ĝis revido**{До свидания}! **Bonan ŝancon**{Удачи}!

## 1. Приветствия и прощания

| Esperanto | Русский |
|---|---|
| Saluton | Привет, здравствуйте |
| Bonan matenon | Доброе утро |
| Bonan tagon | Добрый день |
| Bonan vesperon | Добрый вечер |
| Bonan nokton | Спокойной ночи |
| Ĝis revido / Ĝis! | До свидания / Пока! |
| Dankon / Ne dankinde | Спасибо / Не за что |
| Bonvolu | Пожалуйста (просьба) |

Пожелания стоят в винительном падеже с окончанием **-n**: *bona tago → Bonan tagon!* (как русское «Доброго дня!»).

## 2. Как представиться

- **Kiel vi nomiĝas?** — Как тебя (Вас) зовут?
- **Mi nomiĝas Nataŝa. / Mi estas Nataŝa.** — Меня зовут Наташа. / Я Наташа.
- **Estas plezuro! / Agrable!** — Очень приятно!
- **Kiel vi fartas? — Bone, dankon.** — Как дела? — Хорошо, спасибо.

## 3. Личные местоимения

| Esperanto | Русский |
|---|---|
| mi | я |
| vi | ты, вы, Вы |
| li / ŝi / ĝi | он / она / оно (о предметах) |
| ni | мы |
| ili | они |
| oni | «люди», неопределённо-личное |

**vi** — и «ты», и «Вы», и «вы». Притяжательные получаются добавлением **-a**: *mi → mia* (мой), *vi → via* (твой), *ŝi → ŝia* (её).

## 4. Глагол «esti»

В эсперанто глаголы **не меняются по лицам**: настоящее время всегда оканчивается на **-as**. Вот и всё спряжение!

| Лицо | ESTI | Пример |
|---|---|---|
| mi | **estas** | Mi estas Nataŝa. |
| vi | **estas** | Ĉu vi estas serbo? |
| li / ŝi | **estas** | Luis estas argentinano. |
| ni | **estas** | Ni estas amikoj. |
| ili | **estas** | Ili estas en Prago. |

Вопрос «да/нет» начинается с **ĉu**: *Ĉu vi estas serbo?* — Вы серб? Отрицание — **ne** перед глаголом: *Mi ne estas serbo.*

## 5. Откуда вы?

- **De kie vi estas?** — Откуда вы?
- **Mi estas el Beogrado / el Rusio.** — Я из Белграда / из России.
- **Mi loĝas en Prago.** — Я живу в Праге.

Женский род образуется суффиксом **-in-**: *serbo → serb**in**o*, *amiko → amik**in**o* (подруга). Все существительные оканчиваются на **-o**, множественное число — **-j**: *amikoj*.

| Он | Она | Русский |
|---|---|---|
| serbo | serbino | серб, сербка |
| ruso | rusino | русский, русская |
| argentinano | argentinanino | аргентинец, аргентинка |
| ĉeĥo | ĉeĥino | чех, чешка |
| italo | italino | итальянец, итальянка |
| hispano | hispanino | испанец, испанка |

## 6. Произношение

| Буквы | Как читаются | Пример |
|---|---|---|
| c | «ц» | centro, paco |
| ĉ / ŝ / ĵ | «ч» / «ш» / «ж» | Ĉu, Nataŝa, ĵurnalo |
| ĝ | «дж» | Ĝis |
| ĥ | «х» | ĉeĥo |
| j | «й» | amikoj |
| ŭ | краткое «у» («ў») | hodiaŭ |
| g | всегда «г» | vesperon… agrable |

## 7. Полезно знать

Одна буква — один звук, и ударение **всегда на предпоследнем слоге**: *sa-LU-ton, DAN-kon*. Части речи видны по окончаниям: **-o** — существительное, **-a** — прилагательное, **-e** — наречие, **-as** — глагол сейчас.

## Проверьте себя

Mi [[*estas|esti|estis]] Nataŝa.

Nataŝa estas [[serbo|*serbino|serba]].

[[*Ĉu|Kiel|Kie]] vi estas ruso?

Ni estas [[amiko|*amikoj|amikon]].

Vespere ni diras: [[Bonan matenon|*Bonan vesperon|Bonan nokton]].

В эсперанто «estas» — форма для всех лиц. ( V / F ){V}

Ударение в эсперанто всегда на последнем слоге. ( V / F ){F}
