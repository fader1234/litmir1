## Conoce a Zosia y a Mark

Mark Russo es un fotógrafo de Nueva York. Zofia —Zosia— es una periodista de Cracovia. Juntos llegan a Varsovia para hacer un reportaje sobre leyendas polacas, y así empieza la novela «Cień Bazyliszka».

Pasa el ratón por encima de una palabra (o tócala) para ver su traducción.

> — **Dzień dobry**{Buenos días}! **Jestem**{Soy} Zofia Kamińska.
> — **Dzień dobry, pani Kamińska**{Buenos días, señora Kamińska}. **Mam na imię**{Me llamo} Mark.
> — **Jesteśmy na ty**{Nos tuteamos}! **Jestem Zosia**{Soy Zosia}.
> — **Cześć, Zosiu**{Hola, Zosia}! **Miło mi**{Encantado}.
> — **Mnie też**{Igualmente}. **Skąd jesteś?**{¿De dónde eres?}
> — **Jestem z Nowego Jorku**{Soy de Nueva York}. **A ty?**{¿Y tú?}
> — **Jestem z Krakowa**{Soy de Cracovia}. **Jestem Polką**{Soy polaca}. **Jak się masz?**{¿Qué tal estás?}
> — **Dobrze, dziękuję**{Bien, gracias}! **Do zobaczenia**{¡Hasta luego!}!

## 1. Saludos y despedidas

| Polski | Español |
|---|---|
| Cześć | Hola / Chao (informal) |
| Dzień dobry | Buenos días, buenas tardes (formal) |
| Dobry wieczór | Buenas noches (al llegar) |
| Dobranoc | Buenas noches (al irse a dormir) |
| Do widzenia | Adiós (formal) |
| Do zobaczenia / Na razie | Hasta luego / Nos vemos |
| Dziękuję / Proszę | Gracias / Por favor, de nada |
| Przepraszam | Perdón, disculpe |

**Dzień dobry** es el «hola» educado de todo el día, hasta la tarde. **Proszę** significa «por favor», «de nada» y también «aquí tiene».

## 2. Presentarse

- **Jak masz na imię?** — ¿Cómo te llamas? (el nombre)
- **Mam na imię Mark.** — Me llamo Mark. (literalmente: «tengo de nombre Mark»)
- **Jak się nazywasz?** — ¿Cómo te apellidas? / ¿Cómo te llamas?
- **Nazywam się Kamińska.** — Me apellido Kamińska.
- **Miło mi.** — Encantado / Encantada.
- **Jak się masz? — Dobrze. / Świetnie. / Tak sobie.** — ¿Qué tal? — Bien. / Genial. / Así así.

Cuando llamas a alguien, el nombre cambia (es el caso vocativo): *Zosia → **Zosiu**, Mark → **Marku***.

## 3. Tú y usted: «ty» y «pan / pani»

En polaco el trato formal no usa «vy» ni «usted», sino **pan** (señor) y **pani** (señora), con el verbo en tercera persona:

- **Skąd jesteś?** — ¿De dónde eres? (ty)
- **Skąd pan jest? / Skąd pani jest?** — ¿De dónde es usted?

Pasar al «ty» es un pequeño ritual: *Jesteśmy na ty* — «nos tuteamos».

## 4. Pronombres personales

| Polski | Español |
|---|---|
| ja | yo |
| ty | tú |
| on / ona / ono | él / ella / ello (neutro) |
| my | nosotros |
| wy | vosotros / ustedes |
| oni / one | ellos (con algún hombre) / ellas (sin hombres) |

Como en español, el pronombre casi siempre se omite: **Jestem z Krakowa** = «Soy de Cracovia».

## 5. El verbo «być» (ser / estar)

El polaco tiene un solo verbo para «ser» y «estar»: *Jestem Zosia* — «Soy Zosia»; *Jestem w Warszawie* — «Estoy en Varsovia».

| Persona | BYĆ | Ejemplo |
|---|---|---|
| ja | **jestem** | Jestem Zosia. |
| ty | **jesteś** | Jesteś fotografem? |
| on / ona / pan / pani | **jest** | Mark jest z Nowego Jorku. |
| my | **jesteśmy** | Jesteśmy na ty. |
| wy | **jesteście** | Jesteście z Polski? |
| oni / one | **są** | Mark i Zosia są w Warszawie. |

La negación es la palabra **nie**, separada: **nie jestem, nie jesteś, nie jest…** *Nie jestem Polakiem.* — No soy polaco.

## 6. ¿De dónde eres?

- **Skąd jesteś? / Skąd pan jest?** — ¿De dónde eres? / ¿De dónde es usted?
- **Jestem z Polski / z Krakowa / z Warszawy.** — Soy de Polonia / de Cracovia / de Varsovia.
- **Jestem z Hiszpanii / z Rosji / z Argentyny.** — Soy de España / de Rusia / de Argentina.

Después de **z** («de») la palabra cambia la terminación: *Polska → z Polski, Kraków → z Krakowa*. Las nacionalidades van con mayúscula y, después de **jestem**, toman una terminación especial (la verás bien en la unidad 2):

| Él | Ella | Español |
|---|---|---|
| Jestem Polakiem | Jestem Polką | soy polaco / polaca |
| Jestem Hiszpanem | Jestem Hiszpanką | soy español / española |
| Jestem Rosjaninem | Jestem Rosjanką | soy ruso / rusa |
| Jestem Amerykaninem | Jestem Amerykanką | soy estadounidense |

## 8. Bueno saberlo

En polaco el acento **casi siempre cae en la penúltima sílaba**: *dzię-KU-ję, War-SZA-wa, do zo-ba-CZE-nia*. Las rayitas sobre las letras (ś, ó, ć…) no marcan el acento: cambian el sonido.
