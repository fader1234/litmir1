## Вторая Прага

Экскурсовод Люцие говорит Луису: «**Pod Prahou je druhá Praha.**{Под Прагой есть вторая Прага.} Staré sklepy, chodby a síně. Tam je krásná akustika.» Она ведёт друзей вниз.

> — **Kde jsme**{Где мы}? — ptá se Luis.
> — **Jsme pod Starým Městem**{Мы под Старым городом}. **Nahoře je náměstí**{Наверху площадь}, **vedle je kostel**{рядом церковь}.
> — A **kde je Karlův most**{где Карлов мост}?
> — **Most je tam**{Мост вон там}, **na řece**{на реке}. **Není daleko**{Недалеко}.
> — **Je tady**{Здесь есть} **světlo**{свет}?
> — Ne. **Světlo je v batohu**{Свет в рюкзаке}. Mark **má baterku**{у Марка фонарик}.
> — **Jsem v podzemí Prahy**{Я в подземелье Праги}… a **tady chci hrát koncert**{здесь я хочу сыграть концерт}!

## 1. Где? — KDE JE…?

- **Kde je** kavárna? — Где кафе?
- **Kde jsou** Jana a Mark? — Где Яна и Марк?
- **Kavárna je tady / tam.** — Кафе здесь / там.
- **Je to daleko / blízko?** — Это далеко / близко?

## 2. V или NA + предложный падеж

Как в русском, «где?» требует **предложного падежа** (по-чешски — *lokál*):

| | Именительный | Где? | |
|---|---|---|---|
| **v** (в) | Praha | **v** Praz**e** | в Праге |
| | kavárna | **v** kavárn**ě** | в кафе |
| | podzemí | **v** podzemí | в подземелье |
| | batoh | **v** batoh**u** | в рюкзаке |
| **na** (на) | náměstí | **na** náměstí | на площади |
| | most | **na** most**ě** | на мосту |
| | ulice | **na** ulici | на улице |
| | nádraží | **na** nádraží | на вокзале |

Как и в русском, с одними местами говорят **v** (*v kavárně, v Praze, v hotelu*), с другими — **na** (*na náměstí, na nádraží, na poště*). Учите их парами с предлогом.

Окончания: женский род на *-a* → **-e / -ě** (*kavárna → v kavárně*), мужской и средний чаще → **-u** или **-ě** (*hrad → na hradě, batoh → v batohu*), слова на *-í* не меняются (*náměstí → na náměstí*).

## 3. Предлоги места

| Čeština | Русский | Пример |
|---|---|---|
| vedle | рядом с | vedle kostela |
| před | перед | před kavárnou |
| za | за | za mostem |
| nad | над | nad řekou |
| pod | под | pod Prahou |
| mezi | между | mezi hradem a mostem |
| naproti | напротив | naproti nádraží |
| nahoře / dole | наверху / внизу | Náměstí je nahoře. |
| vlevo / vpravo | слева / справа | Kostel je vlevo. |

После *před, za, nad, pod, mezi* слово стоит в творительном падеже — как в русском («под Прагой»). Пока запомните фразы целиком.

## 4. Город

| Čeština | Русский | Čeština | Русский |
|---|---|---|---|
| náměstí | площадь | most | мост |
| ulice | улица | řeka | река |
| kostel | церковь | hrad | замок, крепость |
| kavárna | кафе | nádraží | вокзал |
| tramvaj | трамвай | metro | метро |
| obchod | магазин | muzeum | музей |

Прага — город трамваев: *Venku zvoní tramvaje* — на улице звенят трамваи (из романа).

## 5. Есть ли? — JE TADY…?

- **Je tady** kavárna? — Здесь есть кафе?
- **Tady je** metro. — Вот метро. / Здесь метро.
- **Není tady** světlo. — Здесь нет света.

## Проверьте себя

Luis je [[*v Praze|v Praha|na Praze]].

Jana sedí [[v kavárna|*v kavárně|na kavárně]].

Lucie a Mark jsou [[*na náměstí|v náměstí|na náměstě]].

Karlův most je [[v řece|*na řece|pod řeku]].

[[*Kde|Kdo|Co]] je nádraží?

Pod [[Praha|*Prahou|Praze]] je druhá Praha.

«Na nádraží» значит «на вокзале». ( V / F ){V}

«Kde» значит «кто». ( V / F ){F}
