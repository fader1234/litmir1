## ¡Tenemos que encontrar a Jana!

En «Podzemní tajemství» la princesa Ludmila hipnotiza a Jana con su canción, y Jana se va. Luis se despierta en el subsuelo con dolor de cabeza. Esta es una versión simplificada de la escena.

> — **Kde je Jana?**{¿Dónde está Jana?}
> — Šla za princeznou. **Nemohli jsme ji zastavit**{No pudimos detenerla}.
> — **Musíme ji najít!**{¡Tenemos que encontrarla!}
> — Ale kde? **Nevím, kde je**{No sé dónde está}.
> — **Vím, koho hledáš**{Sé a quién buscas}, — dice un guerrero con una armadura antigua.
> — Kdo jsi?
> — Jsem Luboš, **strážce podzemí**{el guardián del subsuelo}.
> — **Můžeš nám pomoct?**{¿Puedes ayudarnos?}
> — **Nemůžu jít s vámi**{No puedo ir con vosotros}. **Ale můžu vám dát tohle**{Pero puedo daros esto}.
> — Luisi, **umíš to přečíst?**{¿sabes leer esto?}
> — **Umím. To jsou noty!**{Sí. ¡Son notas musicales!}

## 1. CHTÍT, querer

| | CHTÍT |
|---|---|
| já | **chci** |
| ty | **chceš** |
| on / ona | **chce** |
| my | **chceme** |
| vy | **chcete** |
| oni | **chtějí** |

Va con un infinitivo o con un sustantivo en acusativo: *Chci tam hrát!* (Luis, capítulo 1) — *Chci kávu.* Para ser educado se usa **chtěl / chtěla bych**, «querría»: *Chtěla bych čaj, prosím.*

## 2. MOCT, poder (ser capaz, tener permiso)

| | MOCT |
|---|---|
| já | **můžu** (mohu) |
| ty | **můžeš** |
| on / ona | **může** |
| my | **můžeme** |
| vy | **můžete** |
| oni | **můžou** (mohou) |

*Mohu, mohou* son más formales; al hablar se oye *můžu, můžou*. Con **Můžu…?** se pide permiso: *Můžu se zeptat?* — ¿Puedo preguntar?

Recuerda a Lucie en la puerta del subsuelo: *«S tak krátkou sukní dolů **nemůžeš**.»* — Con una falda tan corta no puedes bajar.

## 3. MUSET, tener que

| | MUSET |
|---|---|
| já | **musím** |
| ty | **musíš** |
| on / ona | **musí** |
| my | **musíme** |
| vy | **musíte** |
| oni | **musí** |

Es un verbo regular en -í, como *mluvit*. Cuidado con la negación: **nemusím** significa «no tengo que», no «no debo»: *Dnes nemusím pracovat.* — Hoy no tengo que trabajar. «No debo» es **nesmím**: *Nesmíš tam chodit.* — No debes ir allí.

## 4. ¿UMĚT o MOCT? «Poder» tiene dos sentidos

El español usa «saber» y «poder» casi igual que el checo:

| Verbo | Sentido | Ejemplo |
|---|---|---|
| **umět** | saber hacer algo, tener la habilidad | *Luis **umí** hrát na kytaru.* (sabe tocar) *Neumím česky.* (no sé checo) |
| **moct** | poder ahora, tener permiso | *Dnes **nemůžu** hrát, bolí mě ruka.* (hoy no puedo tocar) |

*Umím plavat, ale teď nemůžu — je zima.* — Sé nadar, pero ahora no puedo: hace frío.

## 5. ¿VĚDĚT o ZNÁT? «Saber» y «conocer»

Igual que en español:

| Verbo | Qué sabes | Ejemplo |
|---|---|---|
| **vědět** = saber | un hecho, una respuesta (a menudo + *kde, kdo, co, že…*) | *Nevím, kde je Jana.* |
| **znát** = conocer | una persona, un lugar, una cosa (+ acusativo) | *Lucie zná pražské podzemí.* |

*Vědět* es irregular: **vím, víš, ví, víme, víte, vědí.** *Znát* es regular: *znám, znáš, zná…*

**Já nevím.** — No lo sé. **Já vím!** — ¡Ya lo sé! (lo dice Mark muy orgulloso cuando Lucie lo llama genio).

## Comprueba lo que sabes

Luis [[*chce|chci|chtějí]] hrát v podzemí.

[[*Můžu|Umím|Musím]] se zeptat? — ¿Puedo preguntar?

My [[*musíme|musí|musím]] najít Janu.

Luis [[*umí|může|ví]] hrát na kytaru.

Nevím, [[*kde|kdo|co]] je Jana. — No sé dónde está Jana.

Lucie [[*zná|ví|umí]] pražské podzemí.

«Nemusím» significa «no debo». ( V / F ){F}

«Umím česky» significa «sé hablar checo». ( V / F ){V}
