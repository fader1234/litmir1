## Знакомьтесь: Яна и Луис

Луис — музыкант из Аргентины. В пражском кафе он знакомится с Яной — так начинается роман «Podzemní tajemství».

Наведите курсор на слово (или нажмите на него), чтобы увидеть перевод.

> — **Ahoj**{Привет}! **Já jsem**{Я} Jana. **Jak se jmenuješ?**{Как тебя зовут?}
> — **Ahoj, Jano**{Привет, Яна}! **Jmenuji se**{Меня зовут} Luis. **Těší mě**{Очень приятно}.
> — **Mě taky**{Мне тоже}. **Odkud jsi?**{Откуда ты?}
> — **Jsem z Argentiny**{Я из Аргентины}. **Jsem hudebník**{Я музыкант}. **A ty?**{А ты?}
> — **Jsem z Prahy**{Я из Праги}. **Jsem Češka**{Я чешка}. **Jak se máš?**{Как дела?}
> — **Dobře, děkuju**{Хорошо, спасибо}! **Na shledanou**{До свидания}!
> — **Čau**{Пока}, Luisi!

## 1. Приветствия и прощания

| Čeština | Русский |
|---|---|
| Ahoj | Привет / Пока (неформально) |
| Dobrý den | Здравствуйте, добрый день |
| Dobré ráno | Доброе утро |
| Dobrý večer | Добрый вечер |
| Dobrou noc | Спокойной ночи |
| Na shledanou | До свидания |
| Čau | Пока |
| Děkuju / Prosím | Спасибо / Пожалуйста |

Внимание, русскоговорящим: **Dobrý den** говорят днём, но значит оно просто «здравствуйте». А **prosím** — это и «пожалуйста», и «не за что», и «простите, что?».

## 2. Как представиться

- **Jak se jmenuješ? / Jak se jmenujete?** — Как тебя зовут? / Как Вас зовут?
- **Jmenuji se Jana. / Já jsem Jana.** — Меня зовут Яна. / Я Яна.
- **Těší mě.** — Очень приятно.
- **Jak se máš? — Dobře.** — Как дела? — Хорошо.

Когда к человеку обращаются, имя меняется (звательный падеж): *Jana → **Jano**, Luis → **Luisi***. Это есть и в старом русском: «Отче», «Боже».

## 3. Личные местоимения

| Čeština | Русский |
|---|---|
| já | я |
| ty | ты |
| on / ona / ono | он / она / оно |
| my | мы |
| vy | вы, Вы |
| oni / ony | они |

Местоимение обычно опускают: **Jsem z Prahy** = «Я из Праги».

## 4. Глагол «být»

В отличие от русского, в чешском глагол «быть» в настоящем времени **обязателен**: *Já **jsem** Jana* — «Я Яна».

| Лицо | BÝT | Пример |
|---|---|---|
| já | **jsem** | Já jsem Jana. |
| ty | **jsi** | Jsi hudebník? |
| on / ona | **je** | Luis je z Argentiny. |
| my | **jsme** | Jsme přátelé. |
| vy | **jste** | Jste z Ruska? |
| oni | **jsou** | Jana a Lucie jsou z Prahy. |

Отрицание пишется слитно: **nejsem, nejsi, není, nejsme, nejste, nejsou**. *Nejsem Čech.* — Я не чех.

## 5. Откуда вы?

- **Odkud jsi? / Odkud jste?** — Откуда ты? / Откуда Вы?
- **Jsem z Prahy / z Moskvy.** — Я из Праги / из Москвы.
- **Jsem z Ruska / z Argentiny.** — Я из России / из Аргентины.

После **z** («из») слово меняет окончание, как в русском: *Praha → z Prahy, Rusko → z Ruska*. Национальности пишутся с большой буквы:

| Он | Она | Русский |
|---|---|---|
| Čech | Češka | чех, чешка |
| Rus | Ruska | русский, русская |
| Argentinec | Argentinka | аргентинец, аргентинка |
| Ital | Italka | итальянец, итальянка |
| Španěl | Španělka | испанец, испанка |
| Angličan | Angličanka | англичанин, англичанка |

## 6. Произношение

| Буквы | Как читаются | Пример |
|---|---|---|
| č, š, ž | «ч», «ш», «ж» | čau, Češka |
| ř | звонкое «рж» одновременно | řeka, Dvořák |
| c | «ц» | cesta |
| ch | «х» | chleba |
| ě | «е» (смягчает согласную) | děkuju |
| á, é, í, ó, ú, ů, ý | долгие гласные | dobrý den, máš |
| h | звонкое украинское «г» | Praha |

## 7. Полезно знать

Ударение в чешском **всегда на первом слоге**: *DĚ-ku-ju, NA-shle-da-nou*. Долгота (á, í…) не связана с ударением.

## Проверьте себя

Luis [[*je|jsem|jsou]] z Argentiny.

Já [[je|*jsem|jsi]] Jana.

My [[*jsme|jste|jsou]] přátelé.

Jana je [[Čech|*Češka|Čeští]].

Večer říkáme: [[Dobré ráno|*Dobrý večer|Dobrou noc]].

Ударение в чешском всегда на первом слоге. ( V / F ){V}

«Prosím» значит только «пожалуйста». ( V / F ){F}
