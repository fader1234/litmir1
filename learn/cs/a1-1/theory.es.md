## Conoce a Jana y a Luis

Luis es un músico de Argentina. En una cafetería de Praga conoce a Jana, y así empieza la novela «Podzemní tajemství».

Pasa el ratón por encima de una palabra (o tócala) para ver su traducción.

> — **Ahoj**{¡Hola!}! **Já jsem**{Yo soy} Jana. **Jak se jmenuješ?**{¿Cómo te llamas?}
> — **Ahoj, Jano**{Hola, Jana}! **Jmenuji se**{Me llamo} Luis. **Těší mě**{Encantado}.
> — **Mě taky**{Igualmente}. **Odkud jsi?**{¿De dónde eres?}
> — **Jsem z Argentiny**{Soy de Argentina}. **Jsem hudebník**{Soy músico}. **A ty?**{¿Y tú?}
> — **Jsem z Prahy**{Soy de Praga}. **Jsem Češka**{Soy checa}. **Jak se máš?**{¿Qué tal estás?}
> — **Dobře, děkuju**{Bien, gracias}! **Na shledanou**{¡Adiós!}!
> — **Čau**{Chao}, Luisi!

## 1. Saludos y despedidas

| Čeština | Español |
|---|---|
| Ahoj | Hola / Chao (informal) |
| Dobrý den | Buenos días, buenas tardes (formal) |
| Dobré ráno | Buenos días (por la mañana temprano) |
| Dobrý večer | Buenas noches (al llegar) |
| Dobrou noc | Buenas noches (al irse a dormir) |
| Na shledanou | Adiós |
| Čau | Chao |
| Děkuju / Prosím | Gracias / Por favor, de nada |

**Dobrý den** es el «hola» educado de todo el día. **Prosím** significa «por favor», «de nada» y «¿perdón?».

## 2. Presentarse

- **Jak se jmenuješ? / Jak se jmenujete?** — ¿Cómo te llamas? / ¿Cómo se llama usted?
- **Jmenuji se Jana. / Já jsem Jana.** — Me llamo Jana. / Soy Jana.
- **Těší mě.** — Encantado / Encantada.
- **Jak se máš? — Dobře.** — ¿Qué tal estás? — Bien.

Cuando llamas a alguien, el nombre cambia (es el caso vocativo): *Jana → **Jano**, Luis → **Luisi***.

## 3. Pronombres personales

| Čeština | Español |
|---|---|
| já | yo |
| ty | tú |
| on / ona / ono | él / ella / ello (neutro) |
| my | nosotros |
| vy | vosotros / usted / ustedes |
| oni / ony | ellos / ellas |

Como en español, el pronombre casi siempre se omite: **Jsem z Prahy** = «Soy de Praga».

## 4. El verbo «být» (ser / estar)

El checo tiene un solo verbo para «ser» y «estar»: *Já **jsem** Jana* — «Yo soy Jana»; *Jsem v Praze* — «Estoy en Praga».

| Persona | BÝT | Ejemplo |
|---|---|---|
| já | **jsem** | Já jsem Jana. |
| ty | **jsi** | Jsi hudebník? |
| on / ona | **je** | Luis je z Argentiny. |
| my | **jsme** | Jsme přátelé. |
| vy | **jste** | Jste z Ruska? |
| oni | **jsou** | Jana a Lucie jsou z Prahy. |

La negación se escribe junta, en una sola palabra: **nejsem, nejsi, není, nejsme, nejste, nejsou**. *Nejsem Čech.* — No soy checo.

## 5. ¿De dónde eres?

- **Odkud jsi? / Odkud jste?** — ¿De dónde eres? / ¿De dónde es usted?
- **Jsem z Prahy / z Moskvy.** — Soy de Praga / de Moscú.
- **Jsem z Ruska / z Argentiny.** — Soy de Rusia / de Argentina.

Después de **z** («de») el sustantivo cambia la terminación: *Praha → z Prahy, Rusko → z Ruska*. Las nacionalidades se escriben con mayúscula, al revés que en español:

| Él | Ella | Español |
|---|---|---|
| Čech | Češka | checo |
| Rus | Ruska | ruso |
| Argentinec | Argentinka | argentino |
| Ital | Italka | italiano |
| Španěl | Španělka | español |
| Angličan | Angličanka | inglés |

## 6. Pronunciación

| Letras | Sonido | Ejemplo |
|---|---|---|
| č, š, ž | «ch», «sh» (como en *show*), «zh» (como la *j* francesa) | čau, Češka |
| ř | una «r» vibrante y una «zh» a la vez | řeka, Dvořák |
| c | «ts» | cesta |
| ch | como la *j* española | chleba |
| ě | «ie» | děkuju |
| á, é, í, ó, ú, ů, ý | vocales largas | dobrý den, máš |
| h | una «j» suave y sonora | Praha |

## 7. Bueno saberlo

En checo el acento **siempre cae en la primera sílaba**: *DĚ-ku-ju, NA-shle-da-nou*. La tilde (á, í…) no marca el acento como en español: indica que la vocal es **larga**.

## Comprueba lo que sabes

Luis [[*je|jsem|jsou]] z Argentiny.

Já [[je|*jsem|jsi]] Jana.

My [[*jsme|jste|jsou]] přátelé.

Jana je [[Čech|*Češka|Čeští]].

Večer říkáme: [[Dobré ráno|*Dobrý večer|Dobrou noc]].

En checo el acento cae siempre en la primera sílaba. ( V / F ){V}

«Prosím» solo significa «por favor». ( V / F ){F}
