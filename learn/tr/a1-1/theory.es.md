## Conocé a Robert y a Rosa

La novela «Çöl Gülü»: después de la Gran Catástrofe, Robert busca sobrevivientes en el desierto. Herido, se despierta en un campamento rebelde… y conoce a Rosa.

Pasá el cursor sobre una palabra (o tocala) para ver la traducción.

> — **Merhaba**{¡Hola!}! **Benim adım**{Me llamo} Rosa. **Senin adın ne?**{¿Cómo te llamás?}
> — **Merhaba**{Hola} Rosa. **Ben**{Yo soy} Robert. **Memnun oldum**{Mucho gusto}.
> — **Ben de memnun oldum**{El gusto es mío}. **Nasılsın?**{¿Cómo estás?}
> — **İyiyim**{Estoy bien}, **teşekkürler**{gracias}. **Sen**{¿Y vos} **nasılsın?**{cómo estás?}
> — **Ben de iyiyim**{Yo también estoy bien}. **Burası bir kamp**{Esto es un campamento}. **Biz özgürüz**{Somos libres}.
> — **Görüşürüz**{Nos vemos}, Rosa!

## 2. Cómo presentarse

- **Adın ne?** — ¿Cómo te llamás?
- **Benim adım Rosa. / Ben Rosa.** — Me llamo Rosa. / Soy Rosa.
- **Memnun oldum.** — Mucho gusto.
- **Nasılsın? — İyiyim.** — ¿Cómo estás? — Bien.

## 3. Los pronombres personales

| Türkçe | Español |
|---|---|
| ben | yo |
| sen | vos, tú |
| o | él, ella |
| biz | nosotros |
| siz | ustedes; usted (formal) |
| onlar | ellos, ellas |

El turco no tiene género: **o** significa "él", "ella" y también "eso". Los pronombres muchas veces se omiten, porque la terminación ya muestra la persona.

## 4. El verbo "olmak" (ser, estar)

En turco, "ser / estar" es una **terminación** que se pega a la palabra: *öğrenci* (estudiante) → *öğrenci**yim*** (soy estudiante). No hay un verbo aparte como "soy".

| Persona | OLMAK | Ejemplo |
|---|---|---|
| ben | -(y)ım / -(y)im | Ben öğrenciyim. |
| sen | -sın / -sin | Sen öğrencisin. |
| o | — (-dır) | O öğrenci. |
| biz | -(y)ız / -(y)iz | Biz öğrenciyiz. |
| siz | -sınız / -siniz | Siz öğrencisiniz. |
| onlar | -lar / -ler | Onlar öğrenciler. |

**Armonía vocálica**: la vocal de la terminación se ajusta a la última vocal de la palabra. Después de *a, ı* — **ı**; después de *e, i* — **i**; después de *o, u* — **u**; después de *ö, ü* — **ü**: *Rus**um*** (soy ruso), *Türk**üm*** (soy turco), *iyi**yim*** (estoy bien). Si la palabra termina en vocal, se agrega una **y**.

## 5. ¿De dónde sos?

- **Nerelisin?** — ¿De dónde sos?
- **Moskova’lıyım. / İstanbul’luyum.** — Soy de Moscú. / Soy de Estambul.
- **Rusya’dan geliyorum.** — Vengo de Rusia.

La terminación **-lı / -li / -lu / -lü** significa "de (un lugar)": *İstanbul**lu***, *Moskova**lı***. Las nacionalidades no cambian según el género:

| Él | Ella | Español |
|---|---|---|
| Türk | Türk | turco / turca |
| Rus | Rus | ruso / rusa |
| Arjantinli | Arjantinli | argentino / argentina |
| İtalyan | İtalyan | italiano / italiana |
| İspanyol | İspanyol | español / española |
| İngiliz | İngiliz | inglés / inglesa |

## 6. Pronunciación

| Letras | Sonido | Ejemplo |
|---|---|---|
| c | "y" bien marcada, como la "j" inglesa de *jeans* | cevap |
| ç | "ch" | çöl |
| ş | "sh" | teşekkürler |
| ı (sin punto) | una "i" corta y oscura, entre "i" y "u" | nasılsın |
| ğ | alarga la vocal anterior | dağ |
| ö, ü | como en alemán: "e" y "i" con labios redondeados | Görüşürüz |
| İ, i / I, ı | son letras distintas: "i" / "ı" | İstanbul, Işık |

## 7. Bueno saberlo

El turco usa el alfabeto latino, y casi todas las letras suenan siempre igual. El acento cae normalmente en la última sílaba; *mer**ha**ba* es una excepción.
