## Знакомьтесь: Роберт и Роза

Роман «Çöl Gülü»: после Великой Катастрофы Роберт ищет выживших в пустыне. Раненый, он приходит в себя в лагере повстанцев — и знакомится с Розой.

Наведите курсор на слово (или нажмите на него), чтобы увидеть перевод.

> — **Merhaba**{Привет, здравствуйте}! **Benim adım**{Меня зовут} Rosa. **Senin adın ne?**{Как тебя зовут?}
> — **Merhaba**{Здравствуй} Rosa. **Ben**{Я} Robert. **Memnun oldum**{Очень приятно}.
> — **Ben de memnun oldum**{Мне тоже приятно}. **Nasılsın?**{Как ты? Как дела?}
> — **İyiyim**{Я в порядке}, **teşekkürler**{спасибо}. **Sen**{А ты} **nasılsın?**{как?}
> — **Ben de iyiyim**{Я тоже в порядке}. **Burası bir kamp**{Здесь лагерь}. **Biz özgürüz**{Мы свободны}.
> — **Görüşürüz**{Увидимся}, Rosa!

## 1. Приветствия и прощания

| Türkçe | Русский |
|---|---|
| Merhaba | Здравствуйте, привет |
| Selam | Привет (неформально) |
| Günaydın | Доброе утро |
| İyi akşamlar | Добрый вечер |
| İyi geceler | Спокойной ночи |
| Hoşça kal | До свидания (говорит уходящий) |
| Görüşürüz | Увидимся |
| Teşekkürler / Teşekkür ederim | Спасибо |

## 2. Как представиться

- **Adın ne?** — Как тебя зовут?
- **Benim adım Rosa. / Ben Rosa.** — Меня зовут Роза. / Я Роза.
- **Memnun oldum.** — Очень приятно.
- **Nasılsın? — İyiyim.** — Как дела? — Хорошо.

## 3. Личные местоимения

| Türkçe | Русский |
|---|---|
| ben | я |
| sen | ты |
| o | он, она, оно |
| biz | мы |
| siz | вы, Вы |
| onlar | они |

В турецком нет рода: **o** — это и «он», и «она», и «оно». Местоимение часто опускают, ведь окончание глагола и так показывает лицо.

## 4. Глагол «olmak»

В турецком «быть» — это **окончание**, которое приклеивается к слову: *öğrenci* (студент) → *öğrenci**yim*** (я студент). Как в русском, отдельного глагола «есть» нет.

| Лицо | OLMAK | Пример |
|---|---|---|
| ben | -(y)ım / -(y)im | Ben öğrenciyim. |
| sen | -sın / -sin | Sen öğrencisin. |
| o | — (-dır) | O öğrenci. |
| biz | -(y)ız / -(y)iz | Biz öğrenciyiz. |
| siz | -sınız / -siniz | Siz öğrencisiniz. |
| onlar | -lar / -ler | Onlar öğrenciler. |

**Гармония гласных**: гласная окончания подстраивается под последнюю гласную слова. После *a, ı* — **ı**, после *e, i* — **i**, после *o, u* — **u**, после *ö, ü* — **ü**: *Rus**um*** (я русский), *Türk**üm*** (я турок), *iyi**yim*** (я в порядке). Буква **y** вставляется, если слово кончается на гласную.

## 5. Откуда вы?

- **Nerelisin?** — Откуда ты?
- **Moskova’lıyım. / İstanbul’luyum.** — Я из Москвы. / Я из Стамбула.
- **Rusya’dan geliyorum.** — Я приехал(а) из России.

Суффикс **-lı / -li / -lu / -lü** значит «родом из»: *İstanbul**lu***, *Moskova**lı***. Названия национальностей не меняются по роду:

| Он | Она | Русский |
|---|---|---|
| Türk | Türk | турок, турчанка |
| Rus | Rus | русский, русская |
| Arjantinli | Arjantinli | аргентинец, аргентинка |
| İtalyan | İtalyan | итальянец, итальянка |
| İspanyol | İspanyol | испанец, испанка |
| İngiliz | İngiliz | англичанин, англичанка |

## 6. Произношение

| Буквы | Как читаются | Пример |
|---|---|---|
| c | «дж» | cevap |
| ç | «ч» | çöl |
| ş | «ш» | teşekkürler |
| ı (без точки) | «ы» | nasılsın |
| ğ | удлиняет предыдущую гласную | dağ |
| ö, ü | как немецкие ö, ü | Görüşürüz |
| İ, i / I, ı | разные буквы: «и» / «ы» | İstanbul, Işık |

## 7. Полезно знать

Турецкий пишется латиницей, и почти каждая буква читается всегда одинаково. Ударение обычно на последнем слоге: *mer**ha**ba* — исключение.

## Проверьте себя

Senin [[*adın|adım|ad]] ne?

Biz [[*öğrenciyiz|öğrenciyim|öğrencisin]].

Sen [[öğrenciyim|*öğrencisin|öğrenciler]].

Sabah: [[İyi geceler|*Günaydın|İyi akşamlar]]!

«O» может значить и «он», и «она». ( V / F ){V}

Буква «c» в турецком читается как «к». ( V / F ){F}
