## Где Роза?

Раннее утро в лагере. Роберт нигде не может найти Розу и спрашивает Айше — пожилую женщину, которая печёт хлеб для всех.

Наведите курсор на слово (или нажмите на него), чтобы увидеть перевод.

> — **Günaydın**{Доброе утро}, Ayşe Teyze! **Rosa nerede?**{Где Роза?}
> — **Rosa kuyuda**{Роза у колодца}. **Su alıyor**{Набирает воду}.
> — **Ya çocuklar?**{А дети?} **Onlar nerede?**{Где они?}
> — **Çocuklar okulda**{Дети в школе}. **Ders çalışıyorlar**{Делают уроки}.
> — **Siz ne yapıyorsunuz?**{А вы что делаете?}
> — **Ekmek yapıyorum**{Пеку хлеб}. **Sen nereye gidiyorsun?**{А ты куда идёшь?}
> — **Kuyuya gidiyorum**{Иду к колодцу}. **Rosa’yı arıyorum**{Ищу Розу}.
> — **Acele et**{Поторопись}, oğlum. **Rosa seni bekliyor**{Роза тебя ждёт}.

## 1. Где? Окончание -DA / -DE

Русскому «в, на» в турецком соответствует **окончание**. У него два варианта гласной (как у множественного числа) и два варианта согласной:

| После | Последняя гласная a, ı, o, u | Последняя гласная e, i, ö, ü |
|---|---|---|
| большинства звуков | **-da**: kuyu**da**, okul**da**, çadır**da** | **-de**: ev**de**, çöl**de** |
| ç, f, h, k, p, s, ş, t | **-ta**: kamp**ta**, sokak**ta** | **-te**: market**te** |

- **Nerede?** — Где? → *Rosa kuyu**da**.* — Роза у колодца.
- **burada / şurada / orada** — здесь / там / вон там.
- С именами собственными ставится апостроф: *İstanbul**’da**, Ankara**’da***.

К этому окончанию можно присоединить «быть» из первого урока: *Ben evde**yim**.* — Я дома. *Sen neredesin?* — Ты где?

## 2. Куда? Окончание -(Y)A / -(Y)E

Направление «куда» — тоже окончание: **-a / -e** (после гласной — **-ya / -ye**):

| Türkçe | Русский |
|---|---|
| **Nereye?** | Куда? |
| okul**a**, kamp**a** | в школу, в лагерь |
| ev**e** | домой |
| kuyu**ya** | к колодцу |
| İstanbul**’a** | в Стамбул |

## 3. Настоящее продолженное время: -(I)YOR

Это время для «делаю сейчас», и очень часто — для обычных, повседневных действий. Берём глагол, убираем **-mak / -mek** и добавляем **-ıyor / -iyor / -uyor / -üyor** (четырёхвариантная гармония) и личное окончание:

| | yapmak (делать) | gelmek (приходить) |
|---|---|---|
| ben | yap**ıyorum** | gel**iyorum** |
| sen | yap**ıyorsun** | gel**iyorsun** |
| o | yap**ıyor** | gel**iyor** |
| biz | yap**ıyoruz** | gel**iyoruz** |
| siz | yap**ıyorsunuz** | gel**iyorsunuz** |
| onlar | yap**ıyorlar** | gel**iyorlar** |

Часть **-yor** не меняется никогда. По гармонии меняется только гласная перед ней: *gül**ü**yor* (смеётся), *otur**u**yor* (сидит).

**После гласной:** если основа кончается на гласную, добавляется просто **-yor**, а конечные **a / e** превращаются в **ı / i**: *oku → oku**yor***, *ara → ar**ı**yor*, *bekle → bekl**i**yor*.

**Особые случаи:** *gitmek → **gid**iyorum* (t → d), *etmek → **ed**iyorum*, *yemek → **yi**yorum* (есть), *demek → **di**yorum* (говорить).

## 4. Отрицание и вопрос

- **Отрицание**: перед гласной вставляется **-m-**: *yap**m**ıyorum* — я не делаю; *gel**m**iyor* — он не идёт.
- **Вопрос**: отдельная частица **mu** с личным окончанием: *Geliyor **musun**?* — Ты идёшь? *Rosa uyuyor **mu**?* — Роза спит?

После **-yor** частица всегда **mu**, потому что последняя гласная — **o**.
