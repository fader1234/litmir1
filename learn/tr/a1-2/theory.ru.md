## Роза показывает Роберту лагерь

Роберт уже может ходить. Роза ведёт его по лагерю повстанцев в пустыне: палатки, колодец, люди, которых он никогда не видел.

Наведите курсор на слово (или нажмите на него), чтобы увидеть перевод.

> — Rosa, **bu ne?**{что это?}
> — **Bu bir çadır**{Это палатка}. **Burası bizim kampımız**{Это наш лагерь}.
> — **Şu ne?**{А то что?}
> — **Şu bir kuyu**{Это колодец}. **Kampta su var**{В лагере есть вода}, **ama elektrik yok**{но нет электричества}.
> — **Onlar kim?**{Кто они?}
> — **Onlar asiler**{Они повстанцы}. **Benim arkadaşlarım**{Мои друзья}.
> — **Onlar asker mi?**{Они солдаты?}
> — **Hayır, asker değiller**{Нет, они не солдаты}. **Öğretmenler, doktorlar, öğrenciler**{Учителя, врачи, студенты}…
> — **Kampta kaç kişi var?**{Сколько человек в лагере?}
> — **Kırk iki**{Сорок два}. **Bir de köpek**{И ещё собака}!

## 1. Это, то: BU, ŞU, O

| Türkçe | Русский |
|---|---|
| **bu** | это, этот (здесь, рядом со мной) |
| **şu** | то, вот то (рядом с тобой или то, на что я показываю) |
| **o** | то, тот (вон там, далеко) |

- **Bu ne?** — Что это? → **Bu bir çadır.** — Это палатка.
- **Bu kim?** — Кто это? → **Bu Rosa.** — Это Роза.
- **bir** — неопределённый артикль («какой-то, один»): *bir çadır* — (одна) палатка.

Множественное число: **bunlar** (эти), **şunlar**, **onlar** (те; а ещё «они»).

## 2. Множественное число: -LAR / -LER

У множественного числа в турецком две формы. Смотрите на **последнюю гласную** слова:

| Последняя гласная | Окончание | Примеры |
|---|---|---|
| a, ı, o, u | **-lar** | çadır → çadır**lar**, kitap → kitap**lar**, okul → okul**lar** |
| e, i, ö, ü | **-ler** | ev → ev**ler**, öğrenci → öğrenci**ler**, göz → göz**ler** |

**Важно:** после числительного существительное остаётся в **единственном числе**: *iki çadır* (две палатки), *kırk kişi* (сорок человек). Никогда не *iki çadırlar*.

## 3. Вопрос: MI / Mİ / MU / MÜ

Вопрос «да или нет» задаётся с помощью частицы **mı**, которая пишется **отдельно**. Её гласная подчиняется четырёхвариантной гармонии, знакомой вам по первому уроку:

| Последняя гласная | Частица | Пример |
|---|---|---|
| a, ı | **mı** | Asker **mı**? |
| e, i | **mi** | Öğrenci **mi**? |
| o, u | **mu** | Doktor **mu**? |
| ö, ü | **mü** | Türk **mü**? |

Личное окончание присоединяется к **mı**, а не к существительному:

| | |
|---|---|
| Öğrenci **miyim**? | Я студент? |
| Öğrenci **misin**? | Ты студент? |
| Öğrenci **mi**? | Он/она студент? |
| Öğrenci **miyiz**? | Мы студенты? |
| Öğrenci **misiniz**? | Вы студенты? |
| Öğrenci**ler mi**? | Они студенты? |

Ответ: **Evet** (да) / **Hayır** (нет).

## 4. «Не являюсь»: DEĞİL

Чтобы сказать «не есть, не являюсь», после существительного ставят **değil** и присоединяют к нему личное окончание:

| | |
|---|---|
| Asker **değilim**. | Я не солдат. |
| Asker **değilsin**. | Ты не солдат. |
| Asker **değil**. | Он/она не солдат. |
| Asker **değiliz**. | Мы не солдаты. |
| Asker **değilsiniz**. | Вы не солдаты. |
| Asker **değiller**. | Они не солдаты. |

## 5. Есть / нет: VAR и YOK

| Türkçe | Русский |
|---|---|
| Kampta su **var**. | В лагере есть вода. |
| Kampta elektrik **yok**. | В лагере нет электричества. |
| Su **var mı**? — **Var.** / **Yok.** | Вода есть? — Есть. / Нет. |
| Benim bir köpeğim **var**. | У меня есть собака. |

С помощью **var** и **yok** турецкий говорит и «у меня есть» — как в русском (подробнее — в следующих уроках).

## 6. Числа

| | | | | | |
|---|---|---|---|---|---|
| 0 | sıfır | 6 | altı | 20 | yirmi |
| 1 | bir | 7 | yedi | 30 | otuz |
| 2 | iki | 8 | sekiz | 40 | kırk |
| 3 | üç | 9 | dokuz | 50 | elli |
| 4 | dört | 10 | on | 60 | altmış |
| 5 | beş | 11 | on bir | 100 | yüz |

Числа просто ставятся рядом: *on iki* (12), *kırk iki* (42), *yüz yirmi beş* (125). **Kaç?** — Сколько? → *Kaç kişi?* — Сколько человек? (существительное — в единственном числе!)

## Проверьте себя

Bu [[*ne|nerede|nasıl]]? — Bu bir çadır.

İki [[çadırlar|*çadır|çadırı]] var.

Öğrenci[[lar|*ler]] kampta.

Sen doktor [[mısın|misin|*musun]]?

Onlar asker [[*değiller|yok|değilim]].

Kampta elektrik [[var|*yok|değil]].

После числительного турецкое существительное ставится во множественное число. ( V / F ){F}

В лагере сорок два человека. ( V / F ){V}
