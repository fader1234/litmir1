## Семья Фадер из Мендосы

В романе «El misterio de los Fader» Луис привозит Наталью из Москвы в Мендосу, к своему отцу Серхио. Серхио показывает гостье семейный альбом.

> — Mira, Natalia, **esta es mi familia**{это моя семья}.
> — ¡Qué bonito! ¿Quién es este hombre?
> — Es **mi padre**{мой отец}, el **abuelo**{дедушка} de Luis. **Tiene**{У него есть / ему} noventa años en la foto.
> — ¿Y esta mujer **tan elegante**{такая элегантная}?
> — Es **mi mujer**{моя жена}, **la madre**{мать} de Luis.
> — Luis, **¿tienes hermanos?**{у тебя есть братья или сёстры?}
> — No, **soy hijo único**{я единственный сын}. Pero **tengo**{у меня есть} muchos **primos**{двоюродные братья и сёстры} en Mendoza.
> — **Nuestra familia**{наша семья} es grande y un poco **misteriosa**{загадочная}… — dice Sergio, y **sonríe**{улыбается}.

## 1. Семья

| Español | Русский | Español | Русский |

| el padre | отец | la madre | мать |
| los padres | родители | el hijo / la hija | сын / дочь |
| el hermano | брат | la hermana | сестра |
| el abuelo | дедушка | la abuela | бабушка |
| el tío / la tía | дядя / тётя | el primo / la prima | двоюродный брат / сестра |
| el marido | муж | la mujer, la esposa | жена |
| el novio | парень, жених | la novia | девушка, невеста |

Обратите внимание: **los padres** — это «родители», а **los hermanos** — «братья и сёстры» вместе. Мужской род во множественном числе включает и мужчин, и женщин.

## 2. Глагол TENER — «иметь»

По-русски мы говорим «у меня есть брат». По-испански — «я имею брата»: **Tengo un hermano.**

| | TENER |
|---|---|
| yo | **tengo** |
| tú | **tienes** |
| él / ella / usted | **tiene** |
| nosotros / nosotras | **tenemos** |
| vosotros / vosotras | **tenéis** |
| ellos / ellas / ustedes | **tienen** |

Глагол неправильный: в *yo* — **-go**, а в формах *tú, él, ellos* гласная **e** превращается в **ie**.

С *tener* говорят и о возрасте: **Sergio tiene 70 años.** — Серхио 70 лет.

## 3. Притяжательные: мой, твой, его…

| Чей? | Один предмет | Много предметов |
|---|---|---|
| мой | **mi** padre | **mis** padres |
| твой | **tu** hermana | **tus** hermanas |
| его / её / Ваш | **su** hijo | **sus** hijos |
| наш | **nuestro** abuelo / **nuestra** abuela | **nuestros** / **nuestras** |
| ваш | **vuestro** / **vuestra** | **vuestros** / **vuestras** |
| их / Ваш (мн.) | **su** familia | **sus** primos |

*Su* может значить «его», «её», «их» и «Ваш» — понятно из контекста. *Tu* (твой) пишется без ударения, а *tú* (ты) — с ударением.

## 4. Прилагательные: какой он?

Прилагательные стоят **после** существительного и согласуются в роде и числе: *una familia **grande**, unos hombres **altos***.

| Он | Она | Русский |
|---|---|---|
| alto | alta | высокий |
| bajo | baja | низкий |
| guapo | guapa | красивый |
| simpático | simpática | приятный, симпатичный |
| rubio | rubia | светловолосый |
| moreno | morena | смуглый, темноволосый |
| inteligente | inteligente | умный |
| joven | joven | молодой |
| mayor | mayor | пожилой, старший |

Чтобы описать человека, используем **ser**: **Luis es alto y moreno. Natalia es pelirroja e inteligente.** (Перед словами на *i-* союз *y* превращается в **e**.)

## 5. «Есть» в смысле «существует»: HAY

**Hay** = «есть, имеется» (без указания, у кого). Форма одна для единственного и множественного числа:

- En la foto **hay** tres personas. — На фото три человека.
- En Mendoza **hay** muchos viñedos. — В Мендосе много виноградников.

## 6. По-аргентински

С *vos*: **vos tenés** (вместо *tú tienes*). **¿Tenés hermanos?**

## Проверьте себя

Luis no [[*tiene|tengo|tienen]] hermanos.

Sergio es [[*el padre|la madre|el hijo]] de Luis.

Yo [[tiene|*tengo|tenemos]] dos primas.

Natalia, ¿dónde está [[*tu|tú|su]] familia?

Luis visita a [[su|*sus|tu]] padres en Mendoza.

En la foto [[*hay|es|tiene]] tres personas.

«Los hermanos» могут быть и братья, и сёстры вместе. ( V / F ){V}

Прилагательное в испанском обычно стоит перед существительным. ( V / F ){F}
