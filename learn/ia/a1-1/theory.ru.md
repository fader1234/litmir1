## Знакомьтесь: Роберт и Катерина

Роман «Le Presentimento»: после ядерного апокалипсиса Роберт ищет выживших, чтобы построить «Nostre Utopia». В снегу он находит женщину — русскую Катерину.

Наведите курсор на слово (или нажмите на него), чтобы увидеть перевод.

> — **Salute**{Здравствуйте, привет}! **Io me appella**{Меня зовут} Robert. **Como te appella tu?**{Как тебя зовут?}
> — **Io me appella Katerina**{Меня зовут Катерина}.
> — **Multo placer**{Очень приятно}, Katerina. **Como sta tu?**{Как ты?}
> — **Ben**{Хорошо}, **gratias**{спасибо}. **Ma io ha frigido**{Но мне холодно}.
> — **De ubi es tu?**{Откуда ты?}
> — **Io es de Russia**{Я из России}. **Io es russe**{Я русская}. **E tu?**{А ты?}
> — **Io es un supervivente**{Я выживший}. **Veni con me**{Пойдём со мной}!

## 1. Приветствия и прощания

| Interlingua | Русский |
|---|---|
| Salute! | Привет! Здравствуйте! |
| Bon die | Добрый день |
| Bon matino | Доброе утро |
| Bon vespera | Добрый вечер |
| Bon nocte | Спокойной ночи |
| A revider! | До свидания! |
| Gratias / De nihil | Спасибо / Не за что |
| Per favor | Пожалуйста |

Интерлингва построена на словах, общих для романских языков и английского. Если вы знаете испанский или итальянский — вы уже понимаете большую её часть!

## 2. Как представиться

- **Como te appella tu? / Como se appella vos?** — Как тебя зовут? / Как Вас зовут?
- **Io me appella Robert.** — Меня зовут Роберт.
- **Multo placer!** — Очень приятно!
- **Como sta tu? — Ben, gratias.** — Как дела? — Хорошо, спасибо.

## 3. Личные местоимения

| Interlingua | Русский |
|---|---|
| io | я |
| tu | ты |
| ille / illa / illo | он / она / оно |
| vos | вы, Вы |
| nos | мы |
| illes | они |

## 4. Глагол «esser»

Хорошая новость: в интерлингве глагол **не меняется по лицам**. *Io es, tu es, nos es, illes es* — всё та же форма **es**.

| Лицо | ESSER | Пример |
|---|---|---|
| io | **es** | Io es Robert. |
| tu | **es** | Tu es russe? |
| ille / illa | **es** | Katerina es russe. |
| nos | **es** | Nos es amicos. |
| vos | **es** | Vos es supervivente? |
| illes | **es** | Illes es in le fortressa. |

Вопрос можно начать с **esque**: *Esque tu es russe?* — Ты русская? Отрицание — **non**: *Io non es russe.*

## 5. Откуда вы?

- **De ubi es tu?** — Откуда ты?
- **Io es de Russia / de Moscova.** — Я из России / из Москвы.
- **Io vive in le fortressa.** — Я живу в крепости.

Национальности обычно не меняются по роду и пишутся с маленькой буквы:

| Он | Она | Русский |
|---|---|---|
| russe | russe | русский, русская |
| italiano | italiana | итальянец, итальянка |
| argentin | argentin | аргентинец, аргентинка |
| espaniol | espaniol | испанец, испанка |
| anglese | anglese | англичанин, англичанка |
| francese | francese | француз, француженка |

## 6. Произношение

| Буквы | Как читаются | Пример |
|---|---|---|
| c + e, i | «ц» (или «с») | placer |
| ch | «к» (или «ш» в некоторых словах) | character |
| g + e, i | «дж» | gelate |
| j | «ж» | jornal |
| qu | «кв» / «к» | que, esque |
| h | лёгкий выдох или не читается | ha, homine |

## 7. Полезно знать

Ударение обычно падает на гласную перед последней согласной: *ap-PEL-la, sa-LU-te, gra-TI-as*.

## Проверьте себя

Io [[*es|son|esser]] Robert.

Katerina [[*es|esse|son]] russe.

Nos es [[*amicos|amico|amica]].

[[*Esque|Como|Ubi]] tu es russe?

Le nocte nos dice: [[Bon matino|Bon die|*Bon nocte]].

Глагол «esser» имеет одну форму «es» для всех лиц. ( V / F ){V}

«Gratias» значит «пожалуйста». ( V / F ){F}
