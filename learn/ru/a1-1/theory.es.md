## Conocé a Natalia y a Luis

Natalia es de Moscú; Luis es un argentino de Mendoza. En la novela «Тайна семьи Фадер» se encuentran un día helado en una pista de patinaje de Moscú. Imaginemos su primera conversación.

Pasá el cursor sobre una palabra (o tocala) para ver la traducción.

> — **Привет**{Hola}! **Меня зовут**{Me llamo} Луис. **А как тебя зовут?**{¿Y cómo te llamás?}
> — **Меня зовут Наталья**{Me llamo Natalia}. **Очень приятно**{Mucho gusto}!
> — **Мне тоже**{Igualmente}. **Ты из Москвы?**{¿Sos de Moscú?}
> — **Да**{Sí}, **я из Москвы**{soy de Moscú}. **Я русская**{Soy rusa}. **А ты откуда?**{¿Y vos de dónde sos?}
> — **Я из Мендосы**{Soy de Mendoza}. **Я аргентинец**{Soy argentino}.
> — **Как дела?**{¿Cómo estás?}
> — **Отлично**{Excelente}, **спасибо**{gracias}! **Пока**{Chau}!

| Здравствуйте | Hola, buen día (formal) |
| Доброе утро | Buenos días |
| Добрый день / Добрый вечер | Buenas tardes / Buenas noches |
| Спокойной ночи | Buenas noches (al dormir) |
| До свидания | Adiós |
| Пока | Chau |
| Спасибо / Пожалуйста | Gracias / Por favor, de nada |

**Здравствуйте** es difícil de pronunciar, incluso para los rusos, que a menudo dicen «здра́сте». La primera «в» no se pronuncia: [здра́ствуйте].

## 2. Presentarse

- **Как тебя зовут?** — ¿Cómo te llamás?
- **Как вас зовут?** — ¿Cómo se llama usted?
- **Меня зовут Наталья.** — Me llamo Natalia. (lit. «A mí me llaman Natalia»)
- **Я Луис.** — Soy Luis.
- **Очень приятно!** — ¡Mucho gusto!

## 3. Pronombres personales

| Русский | Español |
|---|---|
| я | yo |
| ты | vos, tú |
| он / она / оно | él / ella / (neutro) |
| мы | nosotros |
| вы / Вы | ustedes / usted |
| они | ellos, ellas |

**ты** es para amigos, familia y chicos; **вы** es para desconocidos, personas mayores y para varias personas.

## 4. El verbo «быть»

Buena noticia: en presente el ruso **no usa el verbo «ser/estar»**. «Soy Natalia» es simplemente **Я Наталья**, literalmente «yo Natalia». Por escrito, entre dos sustantivos, una raya reemplaza al verbo: *Луис — аргентинец.*

| Persona | БЫТЬ | Ejemplo |
|---|---|---|
| я | — | Я Наталья. |
| ты | — | Ты аргентинец? |
| он / она | — | Луис — аргентинец. |
| мы | — | Мы друзья. |
| вы | — | Вы из Москвы? |
| они | — | Они в Мендосе. |

En ruso tampoco hay artículos: *Я врач* — «Soy médico».

## 5. ¿De dónde sos?

- **Ты откуда? / Вы откуда?** — ¿De dónde sos? / ¿De dónde es usted?
- **Я из Москвы.** — Soy de Moscú. (Москва → из Москвы)
- **Я из Аргентины.** — Soy de Argentina. (Аргентина → из Аргентины)
- **Я живу в Мендосе.** — Vivo en Mendoza.

Después de **из** («de») el sustantivo cambia la terminación: *-а → -ы / -и*. Los casos se aprenden de a poco; por ahora, aprendé las frases. Las nacionalidades tienen forma masculina y femenina:

| Él | Ella | Español |
|---|---|---|
| русский | русская | ruso, rusa |
| аргентинец | аргентинка | argentino, argentina |
| испанец | испанка | español, española |
| итальянец | итальянка | italiano, italiana |
| англичанин | англичанка | inglés, inglesa |
| американец | американка | estadounidense |

| В, Н, Р, С, У, Х | ¡falsos amigos! v, n, r, s, u, j | Москва, нос, ресторан |
| Е, Ё, Ю, Я | ie, io, iu, ia | Наталья, ёлка |
| Ж, Ш, Щ, Ч, Ц | zh, sh, shch, ch, ts | жена, хорошо, чай |
| Б, Г, Д, З, И, Й, Л, П, Ф | b, g (gato), d, z (zumbido), i, i breve, l, p, f | Луис, привет |
| Ы | una «i» oscura | ты, вы |

| Э | «e» | это |

## 7. Para saber más

La **о** sin acento suena como **а**: *Москва* [масква́], *хорошо* [харашо́]. El acento es libre y hay que aprenderlo con cada palabra; en los libros para estudiantes se marca: *спаси́бо, приве́т, Ната́лья*.
