## 1. Los pronombres personales · Личные местоимения

| Español | По-русски |
|---|---|
| yo | я |
| tú | ты |
| él / ella / usted | он / она / Вы (вежливо) |
| nosotros / nosotras | мы |
| vosotros / vosotras | вы (в Испании) |
| ellos / ellas / ustedes | они / вы (в Латинской Америке) |

*В испанском местоимение часто не говорят: глагол уже показывает лицо. Hablo = я говорю.*

## 2. El presente: verbos regulares · Настоящее время: правильные глаголы (cap. 1)

| | hablar | comer | vivir |
|---|---|---|---|
| yo | hablo | como | vivo |
| tú | hablas | comes | vives |
| él / ella / usted | habla | come | vive |
| nosotros / nosotras | hablamos | comemos | vivimos |
| vosotros / vosotras | habláis | coméis | vivís |
| ellos / ellas / ustedes | hablan | comen | viven |

*Убираем окончание -ar, -er, -ir и добавляем новое окончание.*

## 3. El presente: verbos irregulares · Неправильные глаголы (cap. 2)

| | ser | estar | tener | ir |
|---|---|---|---|---|
| yo | soy | estoy | tengo | voy |
| tú | eres | estás | tienes | vas |
| él / ella / usted | es | está | tiene | va |
| nosotros / nosotras | somos | estamos | tenemos | vamos |
| vosotros / vosotras | sois | estáis | tenéis | vais |
| ellos / ellas / ustedes | son | están | tienen | van |

*Также: querer (quiero), poder (puedo), venir (vengo, vienes), decir (digo, dices).*

## 4. Ser y estar · Два глагола «быть» (cap. 2)

**ser** — кто, какой, откуда: *Martín es profesor. Marina es rubia. Soy de Moscú.*

**estar** — где и как сейчас: *La ciudad está debajo de la tierra. Martín está nervioso.*

## 5. Hay y está / están · «Есть» и «находится» (cap. 3)

**hay** — что-то есть (новая информация): *En la ciudad hay fuentes.*

**está / están** — где находится конкретный предмет: *La llave está en el bolsillo.*

## 6. Los verbos reflexivos · Возвратные глаголы (cap. 3)

| despertarse | |
|---|---|
| yo | me despierto |
| tú | te despiertas |
| él / ella / usted | se despierta |
| nosotros / nosotras | nos despertamos |
| vosotros / vosotras | os despertáis |
| ellos / ellas / ustedes | se despiertan |

*Как русские глаголы на -ся: просыпаться, одеваться, мыться.*

## 7. Estar + gerundio · Действие прямо сейчас (cap. 4)

estar + **-ando** (-ar) / **-iendo** (-er, -ir): *Estoy leyendo. Están caminando.*

*Показывает, что действие происходит в этот момент.*

## 8. Ir a + infinitivo · Ближайшее будущее (cap. 5)

voy / vas / va / vamos / vais / van + **a** + infinitivo: *Mañana vamos a votar.*

*Как русское «собираюсь сделать», «буду делать».*

## 9. El pretérito indefinido · Прошедшее время (cap. 6 y 7)

*Законченное действие в прошлом. Слова-помощники: ayer, anoche, el lunes, la semana pasada, hace dos días.*

| | hablar | comer | vivir |
|---|---|---|---|
| yo | hablé | comí | viví |
| tú | hablaste | comiste | viviste |
| él / ella / usted | habló | comió | vivió |
| nosotros / nosotras | hablamos | comimos | vivimos |
| vosotros / vosotras | hablasteis | comisteis | vivisteis |
| ellos / ellas / ustedes | hablaron | comieron | vivieron |

**Irregulares:** ser / ir → fui, fuiste, fue… · tener → tuve · estar → estuve · hacer → hice, hizo · poner → puse · venir → vine · decir → dije

*Ser и ir в прошедшем времени одинаковые: Fue un día increíble (был). Fuimos a la plaza (пошли).*
